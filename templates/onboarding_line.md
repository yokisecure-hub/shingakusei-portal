# 入居案内 LINE テンプレート

> 短文・絵文字最小限。入居者側のメリットのみ記載。
> 公式LINEアカウント / 個別チャット どちらでも転用可。
> `{{...}}` 部分は配信前に置換すること。

---

## A. 標準版(初回案内)

```
{{tenant_name}}様

このたびは {{property_name}} へのご入居、
誠におめでとうございます。

入居日からすぐにWi-Fiが使える状態にしたい方へ、
新生活インフラの開通サポートページをご案内します。

▼ こちらから1回で手配可能
{{portal_url}}?src=line

・ネット/電気/ガス/引越し等の申込みが1回で完了
・キャッシュバック特典がある場合あり
・お申込みは任意です

ご不明点はこのトークへどうぞ。
```

---

## B. 短縮版(リマインド用)

```
入居まであと数日となりました。
Wi-Fi/電気/ガスの手配がまだの方は
こちらから1回で完了できます。

{{portal_url}}?src=line

(お申込みは任意です)
```

---

## C. リッチメッセージ用 ALT テキスト

```
新生活インフラ開通サポート — 1回でまとめて手配
```

---

## 配信前チェックリスト

- [ ] `{{portal_url}}` をデプロイ済みURLに置換
- [ ] `?src=line` が末尾に付いていること(クリック計測用)
- [ ] 営業的表現を含めていない / 「任意です」の文を残している
- [ ] 公式LINE配信の場合は配信者ガイドラインに従って配信頻度を制限
