# A8 HTMLタグ貼付けテンプレート
#
# このファイルをコピーして affiliate_links.txt にリネームし、
# A8.net の管理画面で得た HTML タグをサービスごとに貼り付けてください。
#
# 使い方:
#   1) このファイルを affiliate_links.txt にコピー
#        cp affiliate_links.example.txt affiliate_links.txt
#   2) 各サービスごとに「## サービス名」を書く(config.json#services[].name と一致させる)
#   3) その下に A8.net の「広告リンク作成」画面で出る HTML タグを貼り付ける
#      (バナータグでもテキストタグでもOK。複数貼っても先頭1個だけ使われる)
#   4) ドライランで確認
#        python update_affiliate_urls.py affiliate_links.txt --dry-run
#   5) 適用
#        python update_affiliate_urls.py affiliate_links.txt
#   6) 反映
#        git add config.json
#        git commit -m "Update affiliate URLs"
#        git push
#
# 注意:
#   - affiliate_links.txt は .gitignore 済み(GitHub には公開されない)
#   - 適用前に config.json.bak が自動作成される(戻したい場合 mv config.json.bak config.json)
#   - 「## サービス名」を省略した場合、<img alt="..."> から自動推定する
#   - サービス名のマッチは大文字小文字・全角半角・記号差を吸収する
